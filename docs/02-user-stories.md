# 用户故事

> 格式：作为 [角色]，我希望 [做什么]，以便 [得到什么]。

## 助教申请者

1. 作为**助教申请者**，我希望**注册并登录账号**，以便**使用系统进行岗位申请**。
2. 作为**助教申请者**，我希望**填写个人档案（专业、年级、技能等）**，以便**课程组织者了解我的基本情况**。
3. 作为**助教申请者**，我希望**上传 PDF 格式简历**，以便**课程组织者查看我的详细经历**。
4. 作为**助教申请者**，我希望**浏览所有处于开放状态的岗位**，以便**找到适合我的助教或监考机会**。
5. 作为**助教申请者**，我希望**向某个岗位投递申请**，以便**参与该岗位的招聘**。
6. 作为**助教申请者**，我希望**查看我的申请进度（待审核 / 已通过 / 已拒绝）**，以便**及时知道招聘结果**。

## 课程组织者

7. 作为**课程组织者**，我希望**发布助教岗位（标题、课程、要求、人数、类型）**，以便**向学生招募助教或监考**。
8. 作为**课程组织者**，我希望**查看某一岗位下的所有申请者列表**，以便**对比并筛选候选人**。
9. 作为**课程组织者**，我希望**将申请者标记为通过或拒绝**，以便**完成该岗位的招聘流程**。

## 系统管理员

10. 作为**系统管理员**，我希望**查看每位助教申请者已通过岗位的数量与明细**，以便**了解助教工作负荷并避免过载**。
