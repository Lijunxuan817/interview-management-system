# 助教招聘系统 · 项目说明

## 项目一句话

建设一套 Web 应用，支持课程助教、监考等岗位的**在线发布、在线投递、在线筛选与进度查询**，替代微信群 + 表格的分散做法。

## 给谁用

| 角色 | 说明 |
|------|------|
| 助教申请者 | 想申请课程助教、监考等岗位的学生 |
| 课程组织者 | 需要招募助教的任课教师或助教长 |
| 管理员 | 掌握全体助教岗位分配与工作负荷的人 |

## 解决什么问题

- **以前**：微信群发招聘、腾讯文档/Excel 收简历，难追踪、易遗漏、无法查进度
- **以后**：课程组织者在系统发岗位 → 助教申请者在线投递 → 课程组织者在线筛选 → 申请者可查进度 → 系统管理员可看负荷

## 第一版必须完成（MVP）

- 用户注册 / 登录（三种角色）
- 申请者：个人档案、上传 PDF 简历、浏览岗位、投递、查询申请进度
- 课程组织者：发布岗位、查看申请列表、通过 / 拒绝申请
- 系统管理员：查看全体助教工作负荷（已通过岗位数量与列表）
- Redis 分布式锁（投递防并发，Day 12～15 验）

## 第一版不做

- 手机 App（仅 Web）
- 微信支付、短信付费等
- 多级审批、复杂工作流
- AI 技能匹配（第二阶段可选，导师发补丁）

## 开发过程中

- 每天按导师发的 **《DayX-学生逐步操作.txt》** 逐步执行即可
- **允许**用 AI 查报错；**不允许**用 AI 跳过步骤或伪造验收
- 详见 `00-AI使用说明-学生.md`

## 技术栈（固定）

- 后端：Java 17 + Spring Boot 3 + MySQL 8 + Redis
- 前端：HTML + CSS + JavaScript
- 代码托管：GitHub
